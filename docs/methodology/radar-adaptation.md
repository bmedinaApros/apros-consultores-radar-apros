# Adaptación de la metodología a Radar (propuesta, pendiente de aprobación)

La metodología Digital Growth Advisor parte de un cliente con historial. Radar trabaja con **prospectos sin relación previa**. Esta propuesta conserva lo que aplica y marca lo que cambia.

| Elemento de la metodología | Aplicación en Radar |
|---|---|
| HECHO / INFERENCIA / HIPÓTESIS | Se mapea a `observado` / `inferido` / `manual (a validar)` en las observaciones y en cada afirmación del diagnóstico. Una hipótesis nunca se presenta como hecho. |
| Lenguaje consultivo | Se aplica a todo texto generado: sin críticas ("la web está mal"), con "identificamos una oportunidad de…". Validador de frases prohibidas en el servidor. |
| Cadena Observación → Oportunidad → Impacto → Solución → Entregable → Modelo comercial → KPI | Estructura de cada oportunidad del diagnóstico. La observación referencia IDs de observaciones; el resto es propuesta y se marca como tal. |
| Tipo y prioridad (Quick Win, Evolutivo, Proyecto, Servicio recurrente, Transformación) | Se usa tal cual. Alimenta el criterio de "potencial de retainer". |
| Matriz de oportunidades | Se guarda internamente; el diagnóstico muestra solo las 3–5 más relevantes. |
| Dos entregables coherentes (presentación + documento) | Radar genera **PDF de una página + PPTX** desde los mismos datos estructurados, con la misma terminología. El documento formal de 19 secciones queda fuera del piloto. |
| "Si no puedes verificar que una herramienta existe, no afirmes que no existe" | Coincide con la regla "no se pudo verificar". |
| Documentos históricos, relación previa, propuestas anteriores | **No aplican** a prospectos. Se omiten. Si el prospecto fue cliente antes, se trata desde la cartera, no desde Radar. |
| Marca: respetar el manual "del cliente o de nuestra empresa" | Se usa siempre la marca APROS. |
| Contexto de industria y modelo de negocio | Rubro y plantilla por rubro (editables). Datos que la web no revela se capturan a mano y se etiquetan. |
| Inversión / cronograma / equipo | Fuera del diagnóstico inicial: no hay información para estimarlos sin conocer al prospecto. |
